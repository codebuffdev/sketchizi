How to choose the right diagram

Start with the question you need to answer. Use a flowchart to explain sequence and decisions; UML-style diagrams to describe software structure or behaviour; and architecture diagrams to show systems, infrastructure, and service relationships. For Kubernetes and Docker Compose, focus on the resources or services that make up the deployment and how they connect.
