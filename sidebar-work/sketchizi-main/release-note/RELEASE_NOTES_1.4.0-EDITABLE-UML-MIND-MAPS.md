# Sketchizi 1.4.0 — Editable UML + Mind Maps

UML and Mind Map library items are now inserted as native Excalidraw primitives instead of SVG image elements.

## Result
- UML boxes, labels, fields, methods, stereotypes and relationship primitives are native Excalidraw elements.
- Mind Map topics and supporting shapes are native Excalidraw elements.
- Text is real Excalidraw text and can be edited after insertion.
- Eraser icons keep the existing image insertion path.
- Existing Library drag-to-canvas behavior is preserved.

## Compatibility
- Excalidraw remains pinned to 0.18.1.
