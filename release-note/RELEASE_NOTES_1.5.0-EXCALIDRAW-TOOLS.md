# Sketchizi 1.5.0 — Excalidraw 0.18.1 Tools

Enabled Excalidraw 0.18.1 AI/tool integrations through the native embedded editor API.

## Enabled native tools

- Insert image
- Frame tool
- Web Embed
- Draw to shape
- Laser pointer
- Bucket fill
- Lasso selection
- Mermaid to Excalidraw
- Text to diagram / Wireframe to code where supported by Excalidraw

The editor continues to use `@excalidraw/excalidraw` 0.18.1.
