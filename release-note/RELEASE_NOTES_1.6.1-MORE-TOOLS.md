# Sketchizi 1.6.1 — More Tools

Adds a Sketchizi-hosted More Tools launcher anchored to Excalidraw's extra-tools slot.
The menu delegates tool activation to Excalidraw's imperative API and exposes:

- Insert image
- Frame tool
- Web Embed
- Draw to shape
- Laser pointer
- Bucket fill
- Lasso selection
- Text to diagram
- Mermaid to Excalidraw
- Wireframe to code

The existing Eraser, UML, Mind Map, persistence and editable diagram features are retained.
