# Sketchizi 1.2.0 — Built-in UML Library

- Added a dedicated **UML Diagrams** section directly below Eraser Icons.
- Added built-in, offline UML elements: Class, Abstract Class, Interface, Enumeration, Package, Actor, Use Case, Component, Node, Note, Association, Generalization, Realization, Aggregation, and Composition.
- UML elements use the same proven Library drag-to-canvas flow as Eraser icons.
- UML assets are local SVG data URLs and require no network access.
- Favorites and Recently Used now work across both Eraser and UML libraries.
