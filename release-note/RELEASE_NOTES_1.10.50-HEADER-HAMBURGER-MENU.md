- Replaces the Sketchizi logo tile in the desktop/tablet header with a hamburger application-menu button.
- The header button forwards to Excalidraw's existing native application-menu trigger, preserving its folder, recent-file, file, export, and canvas-background actions.
- Hides the duplicate floating native trigger at desktop/tablet widths while keeping the native menu and its dropdown placement intact.
- Retains the existing Icon Library shortcut immediately beside the hamburger.
- Leaves the original native trigger visible on compact layouts where the header previously omitted the brand mark.
