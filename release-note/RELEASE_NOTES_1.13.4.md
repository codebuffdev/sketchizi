# Sketchizi 1.13.4 — Kubernetes Deployment Review Dashboard

## Added
- Unified dashboard summary for current validation findings by severity.
- Review coverage percentage with accessible progress indicator and shortcut to unreviewed findings.
- Remediation checklist completion percentage, active/resolved counts, and shortcut to pending tasks.
- Saved review history summary and direct action to expand history.
- Latest snapshot comparison summary with a shortcut to focus on changed findings.
- Responsive dashboard card layout for narrow panels and desktop half-width windows.

## Scope
All metrics describe diagram-validation and user-managed workflow state. The dashboard does not inspect a live Kubernetes cluster and does not certify production deployment readiness.
