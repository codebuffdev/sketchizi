# Sketchizi 1.13.1

## Kubernetes deployment review comparison filters

- Added filters for all changes, changed/resolved findings, increased severity, changed remediation, and unresolved errors.
- Added text search across resource identifiers, finding codes, and messages.
- Added sorting by severity, finding code, or resource.
- Added an empty state when no findings match the selected filters.
- Included narrow-screen responsive layouts for the comparison controls.

Verification: regression tests, syntax checks, version consistency, and release ZIP integrity. Production build and browser interaction testing were not run because dependencies were unavailable.
