# Sketchizi 1.12.8 — Kubernetes Review History View

## Added
- Dedicated expandable history view with a card for each saved snapshot.
- Capture dates, total findings, severity counts, reviewed/unreviewed totals, and resolved-history counts.
- Direct compare and delete actions from each history card.
- Responsive layout and dark-theme styling.
- History summary helper and UI regression coverage.

- Kubernetes review-history tests and combined regression suite.
- JavaScript syntax checks, package/lockfile version alignment, and ZIP integrity.
- Production build and interactive browser testing were not run in this environment.
