# Sketchizi 1.3.0 — Mind Map Library

Adds a built-in Mind Maps library section below the UML library.

## Included elements

Central Topic, Main Topic, Subtopic, Floating Topic, Summary, Boundary, Relationship, Branch, and Callout.

## Creation flow

All elements use the existing Library drag-to-canvas insertion path. The section also provides a `Create starter mind map` action that places a central topic with six connected branches on the canvas.

The library is local and available offline.
