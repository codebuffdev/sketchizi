Sketchizi Workbench 1.01 — Handoff Receipt & Follow-up Reconciliation

Implemented:
  - Record a manual receipt attestation for a saved handoff note, with reviewer, status (received / received with follow-up / not received), timestamp, and optional note.
  - Keep the handoff note's original author, text, creation timestamp, and point-in-time queue snapshot unchanged when receipt metadata is recorded.
  - Compare saved bounded task references against the current cross-record queue and flag missing tasks, changed finding status, due date, assignee, task category, and tasks now resolved for carry-forward review.
  - Show reconciliation counts and follow-up candidates in the Workbench UI.
  - Include receipt attestations in decision-record Markdown and document-wide handoff Markdown exports.
  - Validate receipt structure and reject claims that manual receipt metadata proves independent verification.
  - Add tests for immutable snapshots and live-queue reconciliation.

Safeguards:
  - Receipt is a manual attestation, not proof of external delivery, recipient acceptance, or independent evidence verification.
  - Reconciliation compares only bounded references saved with the handoff snapshot; it does not represent the complete historical queue and must not be treated as a unique-task total.
  - Reconciliation does not alter canonical finding disposition, evidence, rollout readiness, or deployment authorization.
