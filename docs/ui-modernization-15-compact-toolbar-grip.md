# UI Modernization 15 — Compact Toolbar Grip

## Change
- Replaced the visually oversized drag affordance with a compact, muted six-dot grip.
- Reduced its width and height, removed button-like background/shadow, and kept the grip as the sole desktop drag target.
- Preserved native toolbar buttons, tool handlers, shortcuts, keyboard movement, and mobile horizontal scrolling.

## Verification
- Source-level CSS assertions only; browser rendering and production build have not been verified in this environment.
